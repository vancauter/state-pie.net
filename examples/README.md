# Examples

This folder contains practical setup examples for StatePie.

- one-slice: minimal store with a single slice.
- multiple-slices: one store composed from multiple slices sharing one action family.
- nested-slices: hierarchical feature modeling using path-like slice names and nested state objects.
- middleware: synchronous typed middleware wrapping dispatch.
- selective-subscriptions: selector-based subscriptions that ignore unrelated state changes.

Each example has its own runnable project and stays focused on one store pattern.
